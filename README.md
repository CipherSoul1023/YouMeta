# YouMeta

YouMeta is a career-discovery landing page for South African Grade 9 learners. It helps learners see career exploration as a low-pressure process of curiosity and discovery.

## Stack

React, TypeScript, Vite, standard CSS, ESLint, and npm.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, or preview one with `npm run preview`.

## Structure

`src/components/landing` contains focused landing-page sections, `src/pages/LandingPage.tsx` composes them, and `src/styles` holds global tokens and landing styles.

## Current status

The approved landing page is implemented, including its responsive navigation, career-pathway interaction, sample question, start modal, and lightweight reveal animations. No product flows or backend integrations are included.

## Future areas

Learner onboarding, career-interest assessments, learner profiles, career exploration, subject guidance, and personalised recommendations are intentionally deferred.
